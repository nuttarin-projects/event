# Event Registration Platform
พัฒนาระบบลงทะเบียนกิจกรรมออนไลน์สำหรับกิจกรรมต่าง ๆ 

---
## Features
- ระบบรับลงทะเบียนเข้าร่วมกิจกรรมออนไลน์
- หน้า member แสดงข้อมูลและกิจกรรมที่เข้าร่วม
- ใช้ AJAX สำหรับตรวจสอบข้อมูลแบบ Real-time
